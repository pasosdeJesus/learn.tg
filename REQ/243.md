### 1. Objective

Complete the PWA experience: installability prompt, app icons, user documentation.

### 2. Changes

**Install prompt:**

- Component `components/InstallPrompt.tsx`:
  - Listens for `beforeinstallprompt`.
  - Shows a banner "Install Learn.tg on your home screen".
  - On click, calls `prompt()` and handles user choice.

**App icons:**

- Generate 192x192, 512x512 and maskable versions from `public/logo-learntg.png` (note: `public/icons/` does not exist yet).
- Place in `public/icons/`.

**User documentation:**

- `doc/pwa-user-guide.md`:
  - How to install on Android/iOS.
  - How to use offline.
  - How to create an in-app wallet.

**Developer documentation:**

- `doc/pwa-developer-guide.md`:
  - How the service worker works.
  - How to add new cached routes.
  - How to test offline.

### 3. Acceptance criteria

- [ ] `InstallPrompt` shows when PWA is installable.
- [ ] App installs on Android (Chrome) and iOS (Safari).
- [ ] Icons render correctly.
- [ ] User guide published.
- [ ] Developer guide published.
