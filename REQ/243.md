### 1. Objective

Complete the PWA experience: installability prompt, app icons, user documentation.

### 2. Changes

**Install prompt:** ✅ done

- Component `components/InstallPrompt.tsx`:
  - Listens for `beforeinstallprompt` (`preventDefault` + deferred prompt) and
    for `appinstalled`.
  - Shows a banner "Install Learn.tg on your home screen" ("Instala Learn.tg en
    tu pantalla de inicio").
  - On click, calls `prompt()` and reads `userChoice`; a dismissal (or "not
    now") is remembered for 7 days (`learn.tg.installPromptDismissedAt`).
  - Mounted in `components/Layout.tsx`, next to `OfflineBanner`.
  - Hydration-safe: it renders nothing until the browser announces the event.

**App icons:** ✅ done

- `public/icons/learntg-{192x192,512x512,maskable-512x512}.png`, generated from
  `public/logo-learntg.png` (246x244) with ImageMagick (`-resize` + `-extent`),
  plus `learntg-180x180.png` as the Apple touch icon (`metadata.icons.apple` and
  `metadata.appleWebApp` in `app/layout.tsx`): on iOS/Safari the manifest is not
  used for installation, so without them the home-screen icon is a screenshot.

**User documentation:** ✅ done — `doc/pwa-user-guide.md` (install on
Android/Chrome and iOS/Safari, using it offline, creating the in-app wallet,
troubleshooting).

**Developer documentation:** ✅ done — `doc/pwa-developer-guide.md` (the pieces,
the caching table, how to add a cached route, how to test offline, and the
`next-pwa` vs `serwist` decision that R-#242 also asks for).
