# R-#217: Warnings de consola por fuentes preload no usadas

La consola del navegador muestra en varias páginas el warning:

```
The resource /_next/static/media/*.woff2 was preloaded using link preload but
not used within a few seconds from the window's load event. Please make sure
it has an appropriate `as` value and it is preloaded intentionally.
```

Las fuentes `DM_Sans` y `DM_Mono` (`next/font/google`) se pre-cargan en TODAS
las rutas desde el root layout, aunque muchas páginas no las necesitan en el
primer render.

---

**Created:** 2026-08-29
**Status:** ✅ Implementado 2026-09-08 (falta verificación visual en dev)
**Type:** Limpieza (consola/dev)
**Effort:** Bajo

## 1. Causa

`app/layout.tsx` define `DM_Sans`/`DM_Mono` con `next/font/google`; Next inyecta
`<link rel="preload">` de cada archivo woff2 en cada página. Cuando la página
no usa la fuente en la ventana de carga (p. ej. rutas sin texto en ese subset o
navegaciones), el navegador avisa.

## 2. Especificación (`app/layout.tsx`)

- Desactivar la precarga automática de las dos fuentes
  (`preload: false`); el CSS `@font-face` de next/font las carga bajo demanda
  con `font-display: swap`, sin impacto funcional (las variables
  `--font-dm-sans`/`--font-dm-mono` se mantienen).
- Alternativa evaluada y descartada: pre-cargar solo el subset usado por ruta
  (complejidad por idioma sin beneficio medible en dev).

## 3. Criterios de aceptación

- [ ] Cargando `/en`, `/es`, `/en/gdcluster` y `/en/donations/lensenia` en el
      navegador no aparece el warning de preload de woff2
- [ ] Las tipografías se aplican igual (CSS var + swap); sin FOUT perceptible
