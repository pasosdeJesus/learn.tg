### 1. Objective

Activate the service worker and configure it to cache static assets, the app
shell, and the offline fallback page. Give learn.tg its own PWA manifest.

### 2. Changes

**Current state (verified 2026-09-15):** `next-pwa@^5.6.0` is already a
dependency of `apps/nextjs`, and `next.config.ts` already wraps the config in
`withPWA` (`dest: 'public'`, `register: true`, `skipWaiting: true`) but with
**`disable: true`** and a `runtimeCaching` limited to `diligent-records` plus
`/_next/static`. So this REQ is about enabling and broadening it, not about
installing it.

**`next.config.ts`:**

- `disable: false` (the only flip needed to start; today it is `true`).
- Keep `register: true`, `skipWaiting: true`.
- Extend `runtimeCaching`:
  - Static assets (`/_next/static/*`): `CacheFirst`, 7 days (already present).
  - Pages (`/en/*`, `/es/*`): `NetworkFirst`, 24 hours.
  - API GET (`/api/*` with GET): `NetworkFirst`, 1 hour.
  - API mutations (`/api/*` with POST/PATCH/DELETE): `NetworkOnly`.
- Keep the existing `diligent-records` entry (it caches another app served by
  this same Next app at `/[lang]/diligent-records`).

**Manifest — learn.tg needs its own:**

- `public/manifest.json` **already exists but describes diligent-records**
  (`name: "Diligent Records"`, `start_url: "/en/diligent-records"`,
  `scope: "/en/diligent-records"`, icons under `/icons/diligent-records-*`).
- It is linked only from `app/[lang]/diligent-records/page.tsx`, which injects
  `<link rel="manifest" href="/manifest.json">` at runtime. `app/layout.tsx` has
  **no** manifest link, and `public/icons/` **does not exist** (the diligent
  manifest points at missing icons).
- Therefore: add a learn.tg manifest (e.g. `public/manifest.webmanifest`) with
  `name: "Learn.tg — Learn through games"`, `short_name: "Learn.tg"`,
  `start_url: "/"`, `scope: "/"`, `display: "standalone"`,
  `background_color: "#ffffff"`, `theme_color: "#2B6B4E"`,
  `orientation: "portrait"`, and 192x192 / 512x512 / maskable icons, and link it
  from the root layout metadata (`manifest: '/manifest.webmanifest'`). Leave the
  diligent one untouched.
- The source logo is `public/logo-learntg.png` (not under `/img/`).

**New page `app/offline/page.tsx`:** (does not exist yet)

- Client component.
- Message: "You are offline. Your progress is saved and will sync when connection returns."
- Link to cached content.

**New hook `lib/hooks/useOfflineStatus.ts`:**

- Returns `isOffline` from `navigator.onLine` + online/offline events.

**New component `components/OfflineBanner.tsx`:**

- Shows when offline.
- Message: "You are offline. Your progress will be saved locally."
