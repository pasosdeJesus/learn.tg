#### 1. Objective

Activate the service worker and configure it to cache static assets, the app shell, and the offline fallback page. Update the PWA manifest for learn.tg.

#### 2. Changes

**`next.config.ts`:**

- `disable: false`.
- `register: true`.
- `skipWaiting: true`.
- `runtimeCaching`:
  - Static assets (`/_next/static/*`): `CacheFirst`, 7 days.
  - Pages (`/en/*`, `/es/*`): `NetworkFirst`, 24 hours.
  - API GET (`/api/*` with GET): `NetworkFirst`, 1 hour.
  - API mutations (`/api/*` with POST/PATCH/DELETE): `NetworkOnly`.
- Note: the existing `diligent-records` caching config is preserved.

**`public/manifest.json`:**

- `name: "Learn.tg — Learn through games"`.
- `short_name: "Learn.tg"`.
- `start_url: "/"`.
- `scope: "/"`.
- `display: "standalone"`.
- `background_color: "#ffffff"`.
- `theme_color: "#2B6B4E"`.
- `orientation: "portrait"`.
- Icons: 192x192, 512x512, maskable (generated from `logo-learntg.png`).

**New page `app/offline/page.tsx`:**

- Client component.
- Message: "You are offline. Your progress is saved and will sync when connection returns."
- Link to cached content.

**New hook `lib/hooks/useOfflineStatus.ts`:**

- Returns `isOffline` from `navigator.onLine` + online/offline events.

**New component `components/OfflineBanner.tsx`:**

- Shows when offline.
- Message: "You are offline. Your progress will be saved locally."
