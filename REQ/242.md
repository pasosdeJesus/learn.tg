# R-#242: Offline Crossword


**Link:** https://github.com/pasosdeJesus/learn.tg/issues/242

**Status:** Proposal
**Created:** 2026-09-15
**Type:** Feature
**Priority:** High
**Dependencies:** R-#238, R-#241

---

### 1. Objective

Allow users to complete crosswords offline. Answers are saved locally in a queue and synced when connection returns.

### 2. Changes

**Current state:** `app/[lang]/[pathPrefix]/[pathSuffix]/test/page.tsx` already saves crossword state in `localStorage`.

**New:**

- Cache crossword data (grid, placements) in IndexedDB after first fetch.
- Load from IndexedDB if offline.
- Queue submissions in IndexedDB.
- Sync the queue when online. The sync runs in the page context, so the NextAuth
  session cookie authorizes it (R-#233 Phase 2 removed the API token: never
  persist or replay a token, and if the session expired the sync must re-auth
  instead of failing silently).
- Evaluate migration from `next-pwa` to `serwist` if `next-pwa` has problems.

**New module `lib/offline/queue.ts`:**

```typescript
interface PendingSubmission {
  id: string
  courseId: number
  guideId: number
  grid: Cell[][]
  placements: WordPlacement[]
  walletAddress: string
  createdAt: number
}

export async function queueSubmission(submission: PendingSubmission): Promise<void>
export async function getPendingSubmissions(): Promise<PendingSubmission[]>
export async function removeSubmission(id: string): Promise<void>
export async function syncPendingSubmissions(): Promise<void>
```

**Update `test/page.tsx`:**

- On submit, if offline, queue submission and show "Pending sync" message.
- If online, submit as usual.

**New hook `lib/hooks/useOfflineSync.ts`:**

- Listens for online event.
- Calls `syncPendingSubmissions()`.
- Shows sync status.

### 3. Acceptance criteria

- [ ] Crossword data cached after first fetch.
- [ ] Crossword loadable offline.
- [ ] Submission offline queues.
- [ ] Queue syncs when online.
- [ ] User sees "Pending sync" indicator.
- [ ] Rewards processed after sync.
- [ ] E2E test: complete crossword offline, sync, verify rewards.
- [ ] Decision documented on `next-pwa` vs `serwist`.

### 5. Testing plan

**Unit tests** (new):

- `queueSubmission`, `getPendingSubmissions`, `removeSubmission` work in IndexedDB.
- `syncPendingSubmissions` posts queued submissions when online.

**Manual tests** (documented in `doc/pwa-testing.md`):

1. Open `learn.tg:9001/en/gdcluster/guide1/test` online.
2. Turn off connection.
3. Complete the crossword.
4. Submit: see "Pending sync" message.
5. Turn on connection.
6. Verify submission synced and rewards processed.

**Commands:**

```bash
cd apps/nextjs && make test-hooks
```

**Time:** seconds (unit) + minutes (manual). **Memory:** <1 GB.
