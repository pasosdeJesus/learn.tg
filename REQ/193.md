# R-#193: Protocol and Tool to Audit the Security of All API Endpoints

Ensure every API endpoint under `/api/*` has appropriate authentication and
authorization, and provide a repeatable audit mechanism for present and future
endpoints.

## Motivation

The `/api/admin/calendar/events` endpoint was discovered to be publicly
accessible without any authentication, exposing the verifier's calendar
(interview schedules, blocked times, personal events). Other admin endpoints
also lacked server-side auth, relying solely on a client-side wallet check
in the dashboard UI.

A systematic audit is needed to prevent this from happening again.

## Requirements

### 1. Authentication Classification

Every endpoint must be classified into one of:

| Class | Description | Auth Required |
|-------|-------------|:---:|
| **Public** | No sensitive data (e.g., `/api/countries`, `/api/religions`) | ❌ |
| **User** | User's own data (e.g., `/api/profile`, `/api/update-scores`) | SIWE session |
| **Admin** | Admin/verifier data (e.g., `/api/admin/*`) | SIWE session + verifier wallet |

### 2. Audit Script

Create `bin/audit-api-auth` that:

1. Scans all files under `app/api/` for route handlers
2. Checks each handler has an auth call (`authenticateUser` or `authenticateAdmin`)
3. Reports any unauthenticated endpoint that accesses the database
4. Runs as part of CI (`make audit`)

### 3. Shared Auth Helpers

- `lib/authenticateUser.ts` — validates SIWE session (wallet + token)
- `lib/admin-auth.ts` — validates SIWE session + verifier wallet list
- `lib/admin-fetch.ts` — frontend helper that appends wallet+token to admin API requests

### 4. Documentation

Update `ARCHITECTURE.md` with the authentication policy (done in R-#190).

## Acceptance Criteria

- [ ] `bin/audit-api-auth` script exists and runs without errors
- [ ] All admin endpoints use `authenticateAdmin` (not just client-side check)
- [ ] All user-specific endpoints use `authenticateUser`
- [ ] Public endpoints are explicitly marked/annotated
- [ ] CI fails if a new endpoint lacks appropriate auth
- [ ] 100% of endpoints classified
