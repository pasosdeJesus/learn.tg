# R-#241: Offline Guide Reading


**Link:** https://github.com/pasosdeJesus/learn.tg/issues/241

**Status:** Proposal
**Created:** 2026-09-15
**Type:** Feature
**Priority:** High
**Dependencies:** R-#240

---

### 1. Objective

Allow users to read course guides offline. When a guide is visited online, its content and images are cached. When offline, the guide is served from cache. Progress is saved locally and synced when connection returns.

### 2. Changes

**Cache guide content:**

- In `app/[lang]/[pathPrefix]/[pathSuffix]/page.tsx`, after fetching the guide through `useGuideData` (which uses `authedGet`, the standard same-origin mechanism of R-#235: session cookie, no API token), cache the returned Markdown in IndexedDB.
- Cache the rendered HTML too (avoid re-processing Markdown offline).
- Service worker caches the page route itself (`NetworkFirst`).

**New hook `lib/hooks/useCachedGuide.ts`:**

- Reads guide Markdown from IndexedDB if offline.
- Falls back to network if online.
- Returns `{ markdown, isFromCache }`.

**Update `useGuideData`:**

- When offline, use cached course data (from `useCourse` cache).
- When offline, use cached guide data.

**Progress offline:**

- Store `guide_usuario` progress in IndexedDB when offline.
- Sync when online.

**New hook `lib/hooks/useOfflineProgress.ts`:**

- Reads/writes progress in IndexedDB.
- Syncs to server when online.

### 3. Acceptance criteria

- [ ] Guide content is cached after first visit.
- [ ] Guide is readable offline.
- [ ] Progress made offline is saved.
- [ ] Progress syncs when online.
- [ ] `OfflineBanner` shows during offline reading.
- [ ] E2E test: visit guide online, go offline, reload, guide still visible.

### 5. Testing plan

**Unit tests** (new):

- `useCachedGuide` returns cached Markdown when offline.
- `useOfflineProgress` reads/writes progress in IndexedDB.

**Manual tests** (documented in `doc/pwa-testing.md`):

1. Open `learn.tg:9001/en/gdcluster/guide1` online.
2. Turn off connection.
3. Reload: guide 1 still visible.
4. Mark guide as read offline.
5. Turn on connection.
6. Verify progress synced.

**Commands:**

```bash
cd apps/nextjs && make test-hooks
```

**Time:** seconds (unit) + minutes (manual). **Memory:** <1 GB.
