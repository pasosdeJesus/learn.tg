# R-#198: Migrate learn.tg to `@pasosdejesus/m` Monorepo

`@pasosdejesus/m` v0.15.0 was split into two packages within a monorepo:
`@pasosdejesus/m` (general CLI + shared libraries) and
`@pasosdejesus/mpdj` (Pasos de Jesús extension: ai:framework, req:*,
credentials, blockchain, ia/).

learn.tg must migrate in two phases: temporary symlink for development, then
versions published on npm.

---

## 1. Current state of learn.tg

| File | Relevant content |
|---|---|
| `apps/nextjs/package.json` | `"@pasosdejesus/m": "gitlab:pasosdejesus/m"` (old `main` branch) |
| `apps/nextjs/bin/m` | `import('@pasosdejesus/m/m')` |
| Blockchain imports | `@pasosdejesus/m/blockchain` → must move to `mpdj` |
| `pnpm-lock.yaml` | Reference to commit `c1ccbb04` of `main` |

---

## 2. Phase 1 — Symlink to local monorepo

Assuming the monorepo cloned at `/var/www/adJ-ia/m` with both packages
compiled (`pnpm -r build`).

### 2.1 `apps/nextjs/package.json`

```diff
- "@pasosdejesus/m": "gitlab:pasosdejesus/m"
+ "@pasosdejesus/m": "link:../../../../m/packages/m"
+ "@pasosdejesus/mpdj": "link:../../../../m/packages/mpdj"
```

### 2.2 `apps/nextjs/bin/m`

```diff
- import('@pasosdejesus/m/m')
+ (async () => {
+   try { await import('@pasosdejesus/mpdj') } catch {}
+   await import('@pasosdejesus/m/m')
+ })()
```

## 3. Phase 1.5 — Fix test mock paths

Migration to `@pasosdejesus/mpdj/blockchain/*` broke 66 tests whose
`vi.mock()` still reference `@pasosdejesus/m/blockchain`. These tests do not
block functionality — the app compiles and CLI commands work.
They will be fixed in this intermediate phase before moving to Phase 2 (npm).

### Files to update

Vitest mocks use absolute paths that must reflect the new
structure:

```
vi.mock('@pasosdejesus/m/blockchain', ...)
→ vi.mock('@pasosdejesus/mpdj/blockchain', ...)

vi.mock('@pasosdejesus/m/blockchain/ecosystem-addresses', ...)
→ vi.mock('@pasosdejesus/mpdj/blockchain/ecosystem-addresses', ...)
```

Most of the 66 failures are due to this change. Some tests also
import the real modules (not mock) and must be updated as well.
