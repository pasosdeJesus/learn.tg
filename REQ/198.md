# R-#198: Migrate learn.tg to `@pasosdejesus/m` Monorepo

`@pasosdejesus/m` v0.15.0 se dividió en dos paquetes dentro de un monorepo:
`@pasosdejesus/m` (CLI general + librerías compartidas) y
`@pasosdejesus/mpdj` (extensión Pasos de Jesús: ai:framework, req:*,
credentials, blockchain, ia/).

learn.tg debe migrar en dos fases: symlink temporal para desarrollo, luego
versiones publicadas en npm.

## 2.5 Phase 1.5 — Fix test mock paths

La migración a `@pasosdejesus/mpdj/blockchain/*` rompió 66 tests cuyos
`vi.mock()` aún referencian `@pasosdejesus/m/blockchain`. Estos tests no
bloquean el funcionamiento — la app compila y los comandos CLI funcionan.
Se corregirán en esta fase intermedia antes de pasar a Phase 2 (npm).

### Archivos a actualizar

Los mocks de Vitest usan paths absolutos que deben reflejar la nueva
estructura:

```
vi.mock('@pasosdejesus/m/blockchain', ...)
→ vi.mock('@pasosdejesus/mpdj/blockchain', ...)

vi.mock('@pasosdejesus/m/blockchain/ecosystem-addresses', ...)
→ vi.mock('@pasosdejesus/mpdj/blockchain/ecosystem-addresses', ...)
```

La mayoría de los 66 fallos son por este cambio. Algunos tests también
importan los módulos reales (no mock) y deben actualizarse igual.

### Verificación

```sh
make test  # debe pasar 176/176
```

monorepo no debería afectarlo — el comando sigue en el paquete `m`, no en
