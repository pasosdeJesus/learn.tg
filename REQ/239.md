#### 1. Objective

Replace the `simulateSIWE` helper (which mocks `window.ethereum`) with the real `@learn-tg/pdj-wallet` core used in Node.js. This makes E2E tests more robust and closer to real behavior.

#### 2. Changes

**New helper `e2e/helpers/in-app-wallet.mjs`:**

```javascript
import { createWallet, signSIWE, MemoryStorage } from '@learn-tg/pdj-wallet'

export async function createTestWallet(pin = '123456') {
  return createWallet({ pin, storage: new MemoryStorage() })
}

export async function signSIWEForTest(wallet, message) {
  return signSIWE(message)
}
```

**Migrate specs that use `simulateSIWE`:**

- `premium-course-checkout.spec.mjs`
- `fresh-wallet-first-connect.spec.mjs`
- `guide-claims.spec.mjs`
- `full-flow.spec.mjs`
- Others as needed.

**In each spec:**

1. Create a wallet with `createTestWallet`.
2. Build SIWE message with the wallet's address.
3. Sign with `signSIWE`.
4. Inject signature into the browser context via Puppeteer.
5. The browser POSTs to `/api/auth/callback/credentials` as usual.

#### 3. Acceptance criteria

- [ ] `e2e/helpers/in-app-wallet.mjs` exists.
- [ ] At least 3 specs migrated.
- [ ] Migrated specs pass.
- [ ] `simulateSIWE` removed or marked deprecated.
- [ ] Documentation updated in `doc/e2e-testing.md`.
