# F-#210: 500 Error on /api/check-crossword in development

F-#210: 500 Error on /api/check-crossword in development

## Problem Description
When submitting a completed crossword puzzle in the development environment, the `/api/check-crossword` endpoint returns a 500 Internal Server Error.

**Server Console Symptoms:**
```
POST /api/check-crossword 500 in 215ms
⨯ unhandledRejection: Error: invalid type: boolean `true`, expected enum CodeFrameColorMode
```

## Investigation Findings
The error message (`invalid type: boolean true, expected enum CodeFrameColorMode`) indicates a low-level issue related to the Next.js/SWC compiler configuration or interaction during the request handling, rather than a failure in the functional business logic of the crossword verification route (`apps/nextjs/app/api/check-crossword/route.ts`).

**Note:** This issue is **not reproducible in production**, where crossword submissions correctly verify and trigger scholarship payouts. The problem appears isolated to the development environment's specific SWC/compiler configuration.
