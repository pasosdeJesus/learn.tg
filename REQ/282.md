# R-#282: Verifier: list students enrolled in a paid course

**Link:** https://github.com/pasosdeJesus/learn.tg/issues/282

**Type:** Feature (admin panel)

## 1. Problem

The verifier could see, per paid course, the **aggregate** of purchases (count,
USDT, SLEARN) in the *Premium purchases* widget
(`GET /api/admin/premium-purchases`), but **not the people**: there was no way to
see who is enrolled in a paid course (today the Global Disciples course).

`premium_course_usuario` holds the enrolment (a row = one purchase: `course_id`,
`usuario_id`, amounts, `transaction_hash`, `purchased_at`), but no admin surface
listed it per user.

## 2. Requirements

1. The verifier can open a paid course and see the list of people who bought it.
2. Each row identifies the student and the purchase: display name and real name,
   email, wallet, country, profile score, USDT and SLEARN paid, purchase date.
3. Admin-only: the roster exposes real names, emails and wallets, so the endpoint
   authenticates with `authenticateAdmin` (`doc/api-security.md`).
4. Works for **any** paid course (the GD course is just the first one with
   purchases); no per-course hardcoding.

## 3. Implementation

- **API** `GET /api/admin/premium-purchases/[courseId]`
  (`app/api/admin/premium-purchases/[courseId]/route.ts`): admin-only; returns
  `{ course: { id, titulo, prefijoRuta }, students: [...] }`, joining
  `premium_course_usuario` → `usuario` → `billetera_usuario` → `msip_pais`,
  ordered by `purchased_at DESC`. `400` on a non-numeric id, `404` when the
  course does not exist.
- **UI** `components/admin/PremiumPurchasesWidget.tsx`: the course name in each
  row is now a button (`data-testid="view-enrolled-<courseId>"`) that opens a
  modal listing the enrolled students (`data-testid="enrolled-list"`), with an
  empty message when nobody bought the course.
- **Docs** `doc/admin-guide.md`: the *Premium Purchases* widget row now says the
  course opens the list of enrolled people.

**Out of scope:** pagination (paid courses have few buyers today); an
enrolment concept for **free** courses (participation there is per guide in
`guide_usuario`, not a purchase).
