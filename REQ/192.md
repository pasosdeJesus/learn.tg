# R-#192: SLEARN Contract Integration for Pastor Bonus

Replace the stub in `POST /api/admin/pastor-bonus` with a real SLEARN token
transfer on the Celo blockchain.

## Current State

The endpoint logs the bonus to the `transaction` and `verification_log` tables
but does not actually transfer SLEARN tokens. The admin sees the bonus as
"awarded" but the pastor never receives the tokens.

## Requirements

1. **Get pastor wallet**: Query `billetera_usuario.billetera` for the pastor's
   wallet address.
2. **Transfer SLEARN**: Call `SLEARN.transfer(pastorWallet, 44e2)` using the
   backend wallet (`PRIVATE_KEY` from `apps/.env`).
3. **Wait for confirmation**: Poll for transaction receipt before returning
   success.
4. **Store tx hash**: Save the transaction hash in `transaction.hash` for
   auditability.
5. **Handle errors**: If the transfer fails (insufficient balance, gas, network),
   return a clear error to the admin.

## Technical Details

- **Contract**: SLEARN (ERC-20, 2 decimals) on Celo
- **Amount**: 44 SLEARN (= 4400 in contract units, `44 * 10^2`)
- **Network**: Determined by `NEXT_PUBLIC_NETWORK` env var
- **Backend wallet**: `PRIVATE_KEY` + `NEXT_PUBLIC_ADDRESS` from `apps/.env`
- **Library**: Use `viem` (already in dependencies) — `createWalletClient` +
  `createPublicClient` with `http` transport

## Implementation Sketch

```typescript
import { createWalletClient, createPublicClient, http, parseUnits } from 'viem'
import { privateKeyToAccount } from 'viem/accounts'
import { celo, celoSepolia } from 'viem/chains'

const BONUS_AMOUNT = 44
const SLEARN_DECIMALS = 2

export async function POST(req: NextRequest) {
  const { userId } = await req.json()
  // ... validate, get pastor wallet from DB ...

  const network = process.env.NEXT_PUBLIC_NETWORK === 'celo' ? celo : celoSepolia
  const rpcUrl = process.env.NEXT_PUBLIC_RPC_URL
  const pk = process.env.PRIVATE_KEY
  const slearnAddr = SLEARN_ADDRESSES[network] // from @pasosdejesus/m/blockchain

  const account = privateKeyToAccount(`0x${pk}`)
  const publicClient = createPublicClient({ chain: network, transport: http(rpcUrl) })
  const walletClient = createWalletClient({ account, chain: network, transport: http(rpcUrl) })

  const hash = await walletClient.writeContract({
    address: slearnAddr,
    abi: erc20Abi,
    functionName: 'transfer',
    args: [pastorWallet, parseUnits(String(BONUS_AMOUNT), SLEARN_DECIMALS)],
  })

  await publicClient.waitForTransactionReceipt({ hash })

  // Store tx hash in DB
  await db.updateTable('transaction')
    .set({ hash, synced: true })
    .where(...)
    .execute()
}
```

## Edge Cases

- **Insufficient SLEARN balance**: Return error, log, do NOT record as paid
- **Network timeout**: Retry once, then fail with clear message
- **Pastor has no wallet**: Return error "pastor has no wallet address"
- **Already paid**: Check `transaction` table for existing bonus to avoid duplicates

## Dependencies

- `viem` (already installed)
- `@pasosdejesus/m/blockchain` for SLEARN_ADDRESSES
- `erc20Abi` from `viem` or hardcoded
