# R-#194: Zionist Affiliation Detection in Church Registration

Add three theological questions to the pastor's church registration form that
help pdJ discern whether a church holds Zionist positions. A non-Zionist pastor
will answer: 1=No, 2=Yes, 3=No.

## Motivation

PRINCIPLES.md §4 (Biblical Peace and Justice) and §7 (Funding — "Humanity")
require clean money from non-violent people and organizations. The ICJ has
found a "plausible risk of genocide" in Gaza and the ICC has issued arrest
warrants for war crimes. Understanding a church's theological position on
these matters helps pdJ make informed decisions about which churches have
access to the Global Disciples course content.

## Requirements

### 1. Database

Add three text columns to the `church` table for storing pastoral responses:

| Column | Type | Default | Question |
|--------|------|---------|----------|
| `pastoral_position_israel_covenant` | VARCHAR(3) | `NULL` | Question 1 |
| `pastoral_position_israel_remnant` | VARCHAR(3) | `NULL` | Question 2 |
| `pastoral_position_israel_gaza` | VARCHAR(3) | `NULL` | Question 3 |

Values: `'yes'`, `'no'`, or `NULL` (unanswered).

### 2. UI (Pastor Dialog)

In the pastor's church dialog, add a section below existing fields:

**Theological Position (optional):**

1. Do you believe God has a plan of salvation for ethnic Israel that operates
   through a separate covenant or dispensation, independent of faith in Jesus
   Christ (e.g., restoration of Levitical sacrifices in the millennium)?
2. Do you believe the true Israel of God is exclusively the remnant of Jews
   and Gentiles who believe in Jesus, and that the territorial promises are
   ultimately fulfilled in the new creation?
3. Considering the ICJ has found a "plausible risk of genocide" in Gaza and
   the ICC has issued arrest warrants for war crimes, do you believe Christians
   should unconditionally support the Modern State of Israel?

Each question has a **Yes / No** radio group. All three default to unanswered.
They are optional — not required to submit the form.

A **non-Zionist** pastor would answer: **1=No, 2=Yes, 3=No**.

**Privacy note:** These answers are **private** and only visible to pdJ admins.
They are not displayed on the public church page.

### 3. Access Control: Global Disciples Course

The Global Disciples course (R-#161) is **restricted to non-Zionist churches**.
Access is granted based on the pastoral responses:

| Condition | Access to Global Disciples |
|-----------|---------------------------|
| `pastoral_position_israel_gaza = 'no'` | ✅ Full access |
| `pastoral_position_israel_gaza = 'yes'` | ❌ Access denied |
| `pastoral_position_israel_gaza = NULL` | ⏳ Pending — user sees "Please complete the theological position questions" |

**Implementation:**

```typescript
// app/api/courses/global-disciples/access/route.ts
export async function GET(req: NextRequest) {
  const church = await getChurchByUser(userId)
  if (!church) {
    return NextResponse.json({ access: false, reason: 'No church registered' })
  }
  if (church.pastoral_position_israel_gaza === 'yes') {
    return NextResponse.json({
      access: false,
      reason: 'This course is restricted to churches that do not support unconditional support for the modern State of Israel.'
    })
  }
  if (church.pastoral_position_israel_gaza === null) {
    return NextResponse.json({
      access: false,
      reason: 'Please complete the theological position questions in your church profile.'
    })
  }
  return NextResponse.json({ access: true })
}
```

### 4. API

- `POST /api/church` — accept `pastoral_position_israel_covenant`,
  `pastoral_position_israel_remnant`, `pastoral_position_israel_gaza`
- `PATCH /api/admin/church/:id` — allow admin to view/edit these fields
- `GET /api/admin/church/:id` — return the fields (admin only)
- `GET /api/courses/global-disciples/access` — returns access status

### 5. Admin Visibility

The admin church edit dialog shows the three questions with current answers.
